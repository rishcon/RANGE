# RANGE — прототип реалистичного FPS

Два режима: огневой полигон и дуэль один на один. Арсенал — автомат, снайперская
винтовка с оптикой, пистолет, нож и три вида гранат. Манекены, стальные мишени,
живые бойцы и бот-дуэлянт. У игрока есть полноценное тело, видимое от первого
лица, а тела падают рэгдоллом.
Стек — **TypeScript + Babylon.js + Electron**. Игра запускается как обычная
веб-страница и тем же кодом — как десктопное приложение, которое открывается
во весь экран.

Ассетов в репозитории нет: вся геометрия, текстуры и звуки генерируются
процедурно в рантайме (canvas-текстуры, синтез звука через WebAudio).

---

## Запуск

```bash
npm install
```

**В браузере (дев-режим, hot reload):**

```bash
npm run dev
```

Откроется `http://localhost:5173`.

**Как десктопное приложение (dev: Vite + Electron одной командой):**

```bash
npm run dev:desktop
```

**Режимы.** В главном меню два пункта: «Полигон» — стрельбище с мишенями и
бойцами, «Дуэль 1 на 1» — раунды против бота. В дуэли мишени полигона убираются,
на арене остаётся один противник; счёт ведётся до бесконечности, раунд
перезапускается через 3.5 секунды после смерти любого из бойцов.

**Продакшн-сборка и запуск десктопа:**

```bash
npm run start:desktop
```

Отдельные шаги: `npm run build:web`, `npm run build:electron`, `npm run typecheck`.

> Для дистрибутива (`.exe`, `.dmg`) достаточно добавить `electron-builder` —
> точка входа `dist-electron/main.js`, рендер лежит в `dist/`.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` | движение |
| `SHIFT` | бег |
| `CTRL` / `C` | присед |
| `ПРОБЕЛ` | прыжок |
| `Q` / `E` | наклон влево / вправо |
| `ЛКМ` | огонь (автоматический) |
| `ПКМ` | прицеливание (механический прицел, сужение FOV) |
| `R` | перезарядка |
| `1` | основное оружие; повторное нажатие переключает автомат ⇄ снайперку |
| `2` | пистолет |
| `3` | нож (ЛКМ — быстрый удар, ПКМ — сильный) |
| `4` / `5` / `6` | осколочная / дымовая / светошумовая граната |
| колесо мыши | перебор оружия · `X` — предыдущее |
| `F` | сбросить мишени и следы |
| `F11` | полноэкранный режим (десктоп) |
| `ESC` | пауза |

Прицеливание — **переключатель**: ПКМ включает прицел, повторное нажатие выключает,
держать кнопку не нужно.

Гранаты бросаются с удержания: зажать ЛКМ — замах, отпустить — дальний бросок;
ПКМ — короткий подброс под ноги.

## Что реализовано

**Персонажи.** Процедурная модель человека из примитивов: таз, позвоночник,
грудь с разгрузкой, шея, голова в шлеме, руки и ноги с суставами — всё
собирается кодом, без единого файла модели. Анимации тоже процедурные:

- **ходьба и бег** — маятник ног и рук по фазе шага, наклон корпуса, качание таза
  и контрвращение плеч;
- **присед** — угол в коленях считается аналитически. Если бедро повернуть на `A`,
  а колено на `−2A`, стопа остаётся ровно под тазом, а таз опускается на
  `2·L·(1−cos A)`. Поэтому ноги не разъезжаются и IK не нужен: движку задаётся
  нужная просадка, а угол решается обратной задачей;
- **прыжок** — на взлёте ноги подбираются, при падении вытягиваются вниз;
- **смерть** — верлет-рэгдолл: кости снимаются с иерархии и дальше их положение
  считает физика. 16 частиц в суставах связаны ограничениями по длине костей,
  плюс мягкие стяжки, которые не дают корпусу сложиться и выворачивают локти и
  колени не дальше предела. Тело подхватывает собственную скорость и импульс
  пули, бьётся о землю с трением и остаётся лежать так, как упало. Полноценный
  физдвижок ради этого не нужен — хватает 16 точек и семи итераций решателя.

**Тело игрока.** Видно при взгляде вниз: грудь, таз и ноги приседают, шагают и
прыгают вместе с камерой. Голова, шея и руки скрыты — голова перекрывала бы
камеру, а руки дублировали бы вьюмодель оружия. Тело смещено на 10 см назад
относительно камеры: у человека голова вынесена вперёд от центра масс, иначе
взгляд вниз упирается в собственную грудь. В рейкастах тело не участвует.

**Дуэль.** Бот держит дистанцию 12–24 м, стрейфит, проверяет прямую видимость и
стреляет очередями по 3–6 патронов с паузами, задержкой реакции и перезарядкой.
Приседает он только когда дистанция уже устраивает — сидя боец не перемещается,
иначе получается «ходьба вприсядку». Попадание по игроку считается аналитически: насколько близко луч с
разбросом прошёл от центра корпуса. Разброс растёт с дистанцией и когда игрок
движется. У игрока 100 единиц здоровья, попадания отмечаются красной засветкой
по краям экрана.

**Смерть игрока.** При нуле здоровья тело показывается целиком (голова и руки
перестают быть скрытыми) и уходит в тот же рэгдолл, что и у бойцов. Камера
отцепляется, отлетает за спину и медленно облетает тело, постепенно отдаляясь —
видно, как именно оно упало. Управление на это время отключено, вьюмодель оружия
убирается. Через 5 секунд начинается следующий раунд и камера возвращается
от первого лица.

**Бойцы.** Семь противников ходят по маршрутам поперёк линии огня, приседают,
изредка подпрыгивают и разворачиваются к игроку, когда он ближе 18 м. Зоны
поражения те же, что у манекенов (голова / корпус / конечности), гранаты их тоже
задевают. После смерти боец лежит 7 секунд и возвращается в строй.

**Игрок и физика.** Кинематическая капсула на встроенных коллизиях Babylon
(`moveWithCollisions` по эллипсоиду), гравитация, «койот-тайм» и буфер прыжка,
плавная смена стойки с проверкой места над головой, подъём на низкие препятствия
(ящики, мешки с песком), наклоны с упором в стену, шаги по пройденному пути.

**Камера.** Покачивание при ходьбе, дыхание в покое, крен при стрейфе и наклоне,
просадка после приземления (пружина), отдельная поправка от отдачи оружия.

**Арсенал.** Семь слотов с общей механикой доставания/убирания (во время смены
оружие не стреляет):

Три ствола в руках (слоты 1–3) и три вида гранат (4–6). В первом слоте лежит
основное оружие — автомат или снайперка, повторное нажатие «1» меняет их местами.

| Слот | Оружие | Особенности |
| --- | --- | --- |
| 1 | AR-15 | автоматический огонь, 30 патронов, **коллиматорный прицел**: красная марка в центре, поле зрения почти не сужается |
| 1 | M40 SCOPED | болтовая: после каждого выстрела и после перезарядки рука передёргивает затвор и выбрасывает гильзу. Оптика сужает FOV почти в шесть раз, модель прячется, включается сетка прицела с милдотами и шкалой дальности |
| 2 | P-9 | самозарядный пистолет, 12 патронов, двуручный хват |
| 3 | Нож | быстрый и сильный удары, попадание считается по фазе анимации веером лучей |
| 4 | Осколочная | урон по площади с падением от расстояния и проверкой укрытия |
| 5 | Дымовая | плотное облако на 16 секунд, реально перекрывает обзор |
| 6 | Светошумовая | ослепление зависит от дистанции, угла взгляда и прямой видимости; заодно глушит звук |

Гильзы вылетают из окна экстракции, отскакивают от земли со звоном и остаются
лежать на полигоне. У винтовки они крупнее, у пистолета мельче. У болтовой
винтовки гильза вылетает не с выстрелом, а при передёргивании затвора.

Гранаты летят по дуге с отскоками от геометрии уровня (рейкаст по направлению
движения), запал тикает независимо от того, где граната остановилась.

**Огнестрел (на примере AR-15).**

- **Отдача в двух независимых каналах**, как в CS2 / PUBG:
  - *смещение прицела* — детерминированный паттерн из 30 шагов, рандомизация
    (`recoilJitter`), нарастание по ходу очереди (`recoilRampPerShot`), ослабленные
    первые выстрелы и низкочастотный дрейф со **своей фазой у каждой очереди**,
    так что паттерн нельзя выучить наизусть. За магазин набегает около **20°**
    вертикали — удержать зажим без оттяжки мыши вниз невозможно;
  - *тряска камеры* (`viewPunch`) — пружинный импульс на каждый выстрел, который
    дёргает картинку, но на точку попадания не влияет. Пуля летит по «боевым»
    углам игрока, а покачивание, дыхание и тряска — чисто визуальные.
- **Руки**: правая обхватывает пистолетную рукоятку (указательный на крючке),
  левая держит цевьё; предплечья уходят вниз-в стороны за кромку кадра. Левая
  рука отыгрывает перезарядку по ключевым кадрам: к магазину, вниз за новым,
  установка, передёргивание затвора, возврат на цевьё.
- **Разброс** конусом с нормальным распределением: база, множители стойки и
  прицеливания, штрафы за движение и прыжок, «бутон» (bloom) за каждый выстрел.
  Раствор прицельной марки в HUD — это и есть реальный конус разброса в пикселях.
- **Рейкаст** по зонам поражения манекена (голова / корпус / конечности),
  трассер, вылет гильзы, дульная вспышка со вспышкой света, декали от пуль,
  частицы по типу поверхности (бетон, металл, дерево, песок).
- **Прицеливание**: сужение FOV, снижение чувствительности, виньетка, точное
  совмещение целика и мушки с центром экрана (проверено проекцией — ≤2 px).
- **Перезарядка** по фазам: отсоединение магазина → падающий магазин (отдельный
  меш с физикой) → установка → передёргивание затвора (только при пустом магазине).
- Анимация ствола: инерция от мыши, покачивание, поза бега, пружины отдачи,
  цикл затвора. Вьюмодель рендерится в отдельной группе с очисткой глубины —
  ствол не проваливается в стены.

**Мир.** Навес над огневым рубежом, разделители дорожек, укрытия, площадка с
пандусом, вал-пулеуловитель, таблички дистанций 10/25/50 м. 15 ростовых
манекенов (падают при «смерти» и встают через 4.5 с) и 6 откидных стальных
мишеней.

**Звук.** Работает в двух режимах. Если в `public/audio/` лежит файл с нужным
именем — играет он; если файла нет, звук синтезируется на лету через WebAudio
(выстрел = сверхзвуковой щелчок + тело + механика, реверб полигона —
сгенерированная импульсная характеристика). Благодаря этому игра запускается без
единого ассета, но принимает настоящие сэмплы без единой строчки кода.

Полный список имён — `SAMPLE_NAMES` в `src/fx/AudioManager.ts`. Расширения
ищутся по порядку: `.ogg`, `.wav`, `.mp3`. Пример: `public/audio/shot-rifle.ogg`.

**Интерфейс.** Главное меню, пауза, настройки (чувствительность, множитель при
прицеливании, FOV, громкость, инверсия Y, покачивание, марка, тени,
постобработка, счётчик FPS, ограничение FPS, масштаб рендера) с сохранением в
`localStorage`. HUD: марка, боезапас, индикаторы стойки/бега/наклона, прогресс
перезарядки, хитмаркер, статистика.

## Структура

```
electron/
  main.ts            процесс Electron: окно, схема app://, CSP, IPC
  preload.ts         мост window.desktop (выход, полноэкранный режим)
src/
  core/
    Game.ts          сборка подсистем и главный цикл
    Config.ts        параметры игрока, камеры и мира
    Settings.ts      настройки + localStorage
    MathUtil.ts      clamp/lerp/damp/пружины/гаусс
  input/
    InputManager.ts  клавиатура, мышь, pointer lock, раскладка
  characters/
    Character.ts     процедурный скелет и анимации (ходьба, присед, прыжок, смерть)
    Ragdoll.ts       верлет-симуляция костей после смерти
    PlayerBody.ts    тело игрока от первого лица
    Enemy.ts         бойцы: поведение, маршруты, урон, respawn
  modes/
    Duel.ts          режим 1 на 1: бот с боевым ИИ, здоровье игрока, счёт раундов
  physics/
    CharacterBody.ts капсула, гравитация, земля, шаг на препятствие
  player/
    Player.ts        углы, движение, стойки, наклоны, анимация камеры
  weapons/
    WeaponConfig.ts  ТТХ всего оружия, паттерны отдачи, параметры гранат
    Types.ts         общий контракт IWeapon и счётчики сессии
    Recoil.ts        паттерн отдачи, возврат прицела и тряска камеры
    models.ts        геометрия всех моделей и рук (фабрика материалов)
    ViewModel.ts     анимация модели в руках: позы, отдача, действия
    Firearm.ts       огонь, разброс, рейкаст, перезарядка, прицеливание
    Melee.ts         нож: два удара, попадание веером лучей
    GrenadeWeapon.ts замах и бросок
    Inventory.ts     слоты, переключение, доставание/убирание
  world/
    Level.ts         геометрия полигона, свет, тени, туман
    Targets.ts       манекены и стальные мишени
    Textures.ts      процедурные текстуры
  fx/
    Effects.ts       попадания, декали, трассеры, гильзы
    Grenades.ts      полёт гранат, взрыв, дым, ослепление
    AudioManager.ts  сэмплы из public/audio + процедурный запасной вариант
public/
  audio/             звуковые файлы (необязательные, см. README внутри)
  ui/
    HUD.ts           DOM-оверлей боя
    Menu.ts          меню, пауза, настройки
```

Порядок кадра важен и зафиксирован в `Game.updateGameplay`:
`weapon.updateAim` (прицел и отдача) → `player.update` (считает «боевые» углы и
камеру) → `weapon.updateFire` (выстрел по свежим боевым углам) → анимация вьюмодели.

## Куда крутить баланс

- `src/weapons/WeaponConfig.ts` — ТТХ всех стволов (темп, урон, разброс,
  паттерн отдачи, `viewPunch*`, `adsFovMul` для зума прицела), параметры ножа
  и гранат (запал, радиус, длительность дыма и ослепления).
- `src/core/Config.ts` — скорости, высоты стоек, гравитация, наклоны, амплитуды
  покачивания камеры.
- `src/characters/Character.ts` — пропорции скелета (`SEG`), палитры формы и
  амплитуды анимаций; `src/characters/Enemy.ts` — маршруты бойцов, темп смены
  поведения и время до respawn.
- `src/weapons/ViewModel.ts` — позы ствола (`HIP`, `ADS`, `SPRINT`, `RELOAD`),
  ключевые кадры левой руки при перезарядке и анимации действий.
- `src/weapons/models.ts` — геометрия каждой модели, точки хвата рук, позы
  (`hip`, `ads`, `sprint`, `reload`) и общий масштаб `VM_SCALE`.

> Позы ствола лучше править аккуратно: `rot.x` вращает модель вокруг рукоятки и
> легко уводит весь ствол за нижнюю кромку кадра — наклон удобнее задавать
> разворотом (`rot.y`) и креном (`rot.z`).

## Особенности реализации, о которые легко споткнуться

- `DynamicTexture.clone()` в Babylon **не копирует содержимое канваса** — клон
  приходит пустым. Для тайлинга используется `tiledCopy()` в `world/Textures.ts`.
- `moveWithCollisions` берёт исходную точку из мировой матрицы меша, поэтому
  перед каждым вызовом она пересчитывается (`CharacterBody.integrate`), иначе
  ломается шаг на препятствие из нескольких перемещений подряд.
- У `DirectionalLight` установка `shadowMinZ` / `shadowMaxZ` / `shadowFrustumSize`
  ломает сравнение глубины — тени просто исчезают. Оставлен авторасчёт границ,
  а размер ортобокса ограничен составом кастеров (периметр и вал теней не дают).
- Купол неба должен быть меньше `camera.maxZ`, иначе отсекается дальней плоскостью.
- Полноэкранному окну Electron на Windows **нельзя** ставить `setAlwaysOnTop(true)`:
  окно тут же уходит из полноэкранного режима и сворачивается. Для захвата
  курсора это и не нужно — pointer lock работает сам по себе.
- В Electron **нельзя** включать `--disable-frame-rate-limit`: со снятым vsync
  Chromium рендерит 300+ FPS, но кадры доезжают до композитора неравномерно и
  картинка дёргается при формально высоком FPS. Vsync оставлен включённым, а
  дополнительный потолок задаётся настройкой «Ограничение FPS» (она держит ровную
  каденцию, поэтому реальная частота кратна частоте монитора).
- ES-модули не грузятся из `file://` (CORS), поэтому в Electron рендер отдаётся
  через собственную схему `app://`.

## Ограничения прототипа

- Нет ИИ и режимов — это стенд для механик стрельбы.
- Дым перекрывает обзор визуально, но не блокирует пули (как и в CS).
- Бойцы на полигоне не стреляют в ответ — это живые мишени. Отвечает огнём
  только бот в режиме дуэли.
- Рэгдолл сталкивается с землёй, но не с геометрией уровня: тело может частично
  войти в ящик, если упасть вплотную к нему.
- Оружие бойца висит на груди, а не в кисти: при креплении к предплечью ствол
